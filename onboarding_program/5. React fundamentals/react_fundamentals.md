# Navigation with React Router
* What are the advantages of client-side routing?
  - Faster navigation, no full page reloads, better user experience, and easier state management between views.

# Working with Lists & User Input
* What are some common issues when working with lists in React?
  - Not using unique keys, performance issues with large lists, and handling controlled vs uncontrolled inputs.

# Styling with Tailwind CSS
* What are the advantages of using Tailwind CSS?
  - Utility-first approach, rapid prototyping, consistent design, and easy customization.

* What are some potential pitfalls?
  - Class name bloat, harder readability, and possible conflicts with custom styles.

# Handling State & User Input
* What happens if we modify state directly instead of using setState?
  - React won’t detect changes, so the UI won’t update and bugs may occur.

# Understanding Components & Props
* Why are components important in React?
  - They enable code reuse, modularity, and separation of concerns, making apps easier to maintain and scale.

# Setting up a React project 
* What challenges did you face during setup?
  - Installing dependencies, configuring tools, and understanding the project structure can be challenging for beginners.
