# Which terminal client did you choose? Why? (Windows Terminal + PowerShell)

I always use Windows Terminal along with PowerShell since they are the default terminal clients on my computer (I'm using an Asus) and since they work pretty well, I don't find it necessary to install other terminal clients. I mostly use the terminal through VS Code, so I don't touch the command prompt of my own computer too often.

## What customizations (if any) did you make?

I don't make any major customizations, apart from changing the color theme to dark since my eyes soar when looking at bright screens for a long time and the dark time reduce my sensory overload.

### What was the most useful command you learned today?

For useful commands, I think that useful ones are always the common ones. So commands like pwd (display the current working path), cd (navigate to any file system), mkdir (to create new directory) are helpful. For new commands, I like cat (display the content of a file) and grep (to find a pattern within a file). Still, I mostly perform these commands manually rather than typing in these commands onto a terminal (mostly because I don't remember them).
